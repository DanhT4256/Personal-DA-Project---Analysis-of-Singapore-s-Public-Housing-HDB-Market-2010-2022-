# Personal-DA-Project---Analysis-of-Singapore-s-Public-Housing-HDB-Market-2010-2022-
Data analysis of Singapore HDB resale prices (2010–2022)

📊 Singapore HDB Resale Market Analysis (2010–2022)
🗂 Data Source

Original dataset: Resale HDB Flat Prices 2000–2022 – Kaggle
https://www.kaggle.com/datasets/syrahmadi/resale-hdb-flat-prices-2000-2022/data

The original dataset contains 4 main files covering HDB resale transactions from 2000–2022.

For this project, the analysis was mainly focused on 2010 onward. A separate dataset was prepared for Remaining Lease analysis from 2015 onward, as this information is available from that period in the data used.

🎯 Introduction & Objectives

This is a personal Data Analysis practice project using Singapore HDB resale transaction data.

The main objectives are to:

Explore HDB resale market trends from 2010–2022.
Analyze transactions by year, location, flat type, price, and storey range.
Explore Remaining Lease and its relationship with transaction patterns.
Identify notable market trends and patterns.
Practice Python, SQL, data cleaning, EDA, visualization, and insight generation.

The project was created mainly for learning and practicing Data Analysis. Feedback and suggestions for improvement are welcome.

🔍 Analysis
Data Preparation
Combined and cleaned data from the original 4 source files.
Standardized dates, locations, flat types, and other relevant fields.
Filtered the main analysis to 2010 onward.
Prepared a separate dataset for Remaining Lease analysis from 2015 onward.

SQL Analysis

Used SQL to explore:

Transaction volume and value

Visualization

Used Power BI to present:

Market trends
Location analysis
Flat type and price distribution
Remaining Lease analysis
💡 Key Findings

Some observations from the analysis:

Transaction activity declined during 2010–2014 and recovered from around 2015.
Transaction activity remained relatively strong during 2020–2021.
3-room, 4-room, and 5-room flats account for most transactions, with 4-room flats being particularly prominent.
Sengkang, Tampines, Jurong West, Woodlands, and Yishun show relatively high transaction activity.
Punggol shows notable growth in the later period.
A large share of transactions falls within the SGD 300,000–650,000 range.
Remaining Lease is an important variable for analyzing transactions from 2015 onward.

These are observations from this dataset and should not be interpreted as definitive conclusions about the entire Singapore housing market.
